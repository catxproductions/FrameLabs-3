# FrameLabs 3

FrameLabs 3 is an independent browser-based structural sandbox. It displays a triangulated frame with pinned supports, editable joints and members, downward joint loads, and a live stress-color map based on a simplified 2D axial spring solver.

Use workspace tools to add joints, connect members, apply loads, pause/resume, recalculate the stress map, and restore the starter frame. The model is for interactive exploration only and is not validated engineering software. Do not rely on it for real structural design or safety decisions. It runs in a modern browser without user setup commands.

AI-agent features are intentionally not part of the current application. Future agent planning files and directories are locally ignored by `.gitignore` until that work is ready to publish.
