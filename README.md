# FrameLabs 3 — UI Foundation

This branch contains the first UI-only implementation of FrameLabs 3, based on the supplied three-screen design references.

## Included screens

- **Start menu:** brand identity, navigation, and a custom visual showcase.
- **Workspace:** central viewport presentation, toolbar, scene list, and inspector layout.
- **Settings:** Graphics and Performance tabs with interactive preview controls.

## Scope

This is a front-end layout and interaction prototype. Navigation, tabs, switches, selectors, sliders, and tool selection provide interface feedback only. They do not run a physics simulation, invoke GPU or CPU compute, change actual rendering quality, or control hardware.

No simulation engine, desktop executable, or backend has been implemented in this branch.

## Run locally

Open index.html in a modern browser. The prototype uses plain HTML, CSS, and JavaScript and requires no package installation.
